Component Breakdown

Every component has a single responsibility and a testable interface.

Collect

FilesystemCollector

Recursive, symlink-safe walk. Emits up to four events per file (Birth/Access/Change/Modify), platform-aware (uses st_birthtime where present), with optional per-file SHA-256.

Collect

LogCollector

Format auto-detection (text, JSON, JSONL/NDJSON, CSV/TSV, EVTX). Flexible field mapping for timestamp/level/user/host, ISO-8601 and epoch parsing, severity inference.

Analyze

TimelineNormalizer

Forces UTC, de-duplicates identical events, produces a globally sorted stream, and computes summary statistics plus time buckets.

Analyze

Correlator

Sliding-window burst detection grouped by host/path/user to surface suspicious activity clusters automatically.

Persist

CaseStore

SQLite (WAL, indexed) case file holding events, sources and case metadata. Thread-safe for background workers; powers faceted queries.

Output

Exporters

Portable CSV/JSON evidence and a self-contained, color-coded HTML timeline report with client-side filtering and severity heat bars.

Security Architecture (Defense in Depth)

Assume hostile evidence and hostile inputs. Controls are preventive, detective and corrective.

  • Integrity of evidence - SHA-256 per artifact, evidence manifests, verification on demand. Detects tampering; supports chain of custody.
  • Tamper-evident audit trail - append-only JSONL hash chain (each record binds the previous hash). Repudiation-resistant; any edit breaks verification.
  • Least privilege & read-only - no writes to evidence, no symlink traversal, depth/size limits. Prevents evidence alteration and scan escape.
  • Input validation - path/length/null-byte checks, directory-escape guards, filename sanitization. Blocks path traversal and injection via crafted filenames.
  • Data protection at rest - optional AES (Fernet) case encryption with PBKDF2-HMAC-SHA256 (600k iters). Protects sensitive case data on removable media.
  • Bounded resource use - max file size, max events, chunked hashing, cancellable worker thread. Resists DoS via giant files or runaway scans.
  • No network egress - the binary opens no sockets; collection is fully offline. Eliminates exfiltration surface.
  • Safe output rendering - all report content HTML-escaped before templating. Neutralizes stored-XSS from malicious log entries.

Portable .exe Packaging & Deployment

Build once, run anywhere Windows - no installer, no registry, no admin rights.

Packaging strategy

build.ps1 invokes PyInstaller --onefile --windowed with the package on --paths, bundles Qt and resources, then writes a SHA256SUMS.txt manifest beside the binary. Optional code-signing step hooks into the same script.

python -m PyInstaller --onefile --windowed \
  --name TimelineBuilder --paths src \
  --collect-submodules timeline_builder \
  run_app.py

Runtime profile

First launch extracts to a temp dir; case stores and audit logs land under %LOCALAPPDATA%\TimelineBuilder (or a user-chosen case path). Portability: ship the exe on USB - settings are per-user, evidence stays read-only.

  • No elevation / no drivers
  • Works fully offline
  • Deterministic, hash-published build artifact

Build & Run

Developer run

pip install -r requirements.txt
.\run.ps1                       # GUI
python -m timeline_builder cli demo --dir demo_case
python -m timeline_builder cli scan demo_case/data \
  demo_case/logs/auth.log --kind auto \
  --out demo.tbcase --html report.html
python -m timeline_builder cli verify demo.audit.jsonl
python -m unittest discover -s tests

Portable build

.\build.ps1 -Install
# -> dist\TimelineBuilder.exe
# -> dist\SHA256SUMS.txt

# Run the portable binary:
.\dist\TimelineBuilder.exe
.\dist\TimelineBuilder.exe --case D:\cases\ir-2026.tbcase

Verification and the full audit chain are exposed both in the GUI (status bar) and the CLI (verify).
