# 04 — Portable .EXE Solution & Release Pipeline

Goal: single-file, **portable**, code-**signed** Windows `.exe`, shipped with an SBOM,
produced by a CI pipeline gated on ISO 27001 / NIST controls.

---

## 1. What "portable .exe" means here

The release is a **jpackage `app-image`** produced by Gradle task
`:gui-launcher:packagePortable`:

```
gui-launcher\build\portable\BurpTester\
├── BurpTester.exe          signed single launcher (GUI, no console)
├── app\
│   └── gui-launcher-1.0.0-all.jar   uber jar: JavaFX + engine + extension logic
└── runtime\                bundled JRE (generated by jpackage, no install)
```

- **Zero-install:** copy the `BurpTester\` folder anywhere (incl. USB) and run
  `BurpTester.exe`. No registry writes, no services, no `Program Files` dependency.
- **Distributable shape:** `scripts/build-portable.ps1` zips the folder into
  `dist\BurpTester-<ver>-portable.zip` and publishes `SHA256SUMS.txt`.
- Optional single-file SFX (IExpress/WrapPack) can wrap the zip for thumb-drive
  distribution; noted here as an ops decision, not the default.

## 2. Packaging technical approach

| Layer | Tool | Note |
|---|---|---|
| Build/uber jar | Gradle `uberJar` task | JavaFX natives + engine all in one jar |
| Runtime + launcher | JDK **jpackage** (`--type app-image`) | Windows exe launcher (`BurpTester.exe`) + bundled runtime |
| Code signing | `signtool` + EV cert | Authenticode SHA-256; timestamp to a trusted TSA |
| Distributable | `scripts/build-portable.ps1` | Zip + `SHA256SUMS.txt` + SBOM assembly |
| SBOM | CycloneDX Gradle plugin + OSV scan | `sbom/README.md` |

## 3. Signing & provenance

```
 Build(CI)      → artifacts unsigned (.exe, .jar)
 Sign job (HSM) → Authenticode timestamped signature
 Attestation    → sha256 manifest + SBOM JSON emitted as release assets
 Release        → GitHub / Artifactory: assets + checksums + SBOM attestation
```

- **Signing happens only in a dedicated CI job** using a hardware-backed EV certificate
  (Azure Key Vault / cloud HSM); developer machines never touch the key → NIST SA-10,
  ISO A.8.28.
- Every release ships `SHA256SUMS.txt`; UI shows publisher to end user at first run.

## 4. SBOM (CycloneDX) & dependency hygiene

- Generated per release: `sbom/bom.burptester-1.0.0.json` — lists every transitive
  dependency with purl coordinates.
- CI **fails** on:
  - version known-vulnerable entries (OSV/NVD feed),
  - license not in allowlist (Apache-2.0, MIT, BSD, EPL, LGPL — inductive),
  - packages not in the lockfile.
- SBOM is **attested** to the build pipeline and published beside the `.exe`.

## 5. Environments / secrets hygiene

| Secret type | Handling |
|---|---|
| HSM signing key | Never leaves Key Vault; short-lived OIDC caller |
| Adjusters/api keys for Burp | Not shipped; analyst supplies in-memory at run time |
| Test JWTs | `ephemeral:true` → zeroized post-run |
| CI tokens | OIDC federation, short-lived, scoped |

## 6. CI/CD pipeline (GitHub Actions example)

```yaml
stages:
  - unittest          # :burp-extension:test :gui-launcher:test
  - sast              # SpotBugs + Gradle dependency audit
  - build             # jars + jlink image
  - sbom              # CycloneDX + vuln/license gates
  - e2e               # run vuln-app fixture (python server.py or docker) ; drive engine
  - sign              # HSM-signed exe + jar (auto-declined if earlier gates fail)
  - release           # attach SHA256SUMS + SBOM attestation
```

**Gate-to-control mapping:** SAST → ISO A.8.28 / NIST SA-11 · SBOM → A.8.8 / SI-2 ·
E2E → A.8.29 / SI-13 · sign+attest → A.8.8 / SA-10 / A08(OWASP).

## 7. Operational runbook highlights (for auditors)

| Operational control | SOP |
|---|---|
| Portable media disposal | Thumb drives: crypto-erase (built-in) then physical destroy OR reuse after declassification |
| Distributable verification | `certutil -hashfile BurpTester-...exe SHA256` vs published manifest |
| Evidence export | Only with explicit operator action; encrypted ZIP optional |
| Crash diagnostics | Optional dump to `logs/` only; UI prompts for deletion |
| Lifecycle EOL | Each release retained 24 months; old versions revoked from distribution index |

## 8. Build & run commands

```bash
# 1) Full portable build (image + zip + checksums) — Windows PowerShell
.\gradlew :gui-launcher:packagePortable
.\scripts\build-portable.ps1 -Version 1.0.0          # unsigned
.\scripts\build-portable.ps1 -Version 1.0.0 -Sign -KeyVaultName sec-corp-avbv
# Outputs
#   gui-launcher\build\portable\BurpTester\BurpTester.exe
#   dist\BurpTester-1.0.0-portable.zip
#   dist\SHA256SUMS.txt
#   dist\sbom\*.json   (after CI SBOM stage)
```
