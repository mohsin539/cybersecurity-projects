The single biggest insider threat across Bangladeshi banks is credential loss via social engineering. This platform lets banks run consented, in-house phishing simulations â€” legally and measurably â€” then train and uplift the workforce while proving control effectiveness to regulators.

Compliance drivers. Bangladesh Bank (BB) governs through the ICT Security Guidelines for Banks & Financial Institutions (2015, revised circulars) and the PSD/Cyber Circular series. Mandatory items addressed: data residency in Bangladesh, mandatory security-awareness & workforce training, audit-log & incident-evidence retention, and secure SDLC. Design is forward-compatible with ISO 27001:2022 & NIST CSF 2.0 adoption.

  • BDT-based risk monetisation (potential loss per clicked/sophisticated lure per job level)

Clone-fidelity templates with {{.FirstName}} {{.Branch}} variables, fully sandboxed rendering (iframe srcdoc + CSP), deterministic link rewriting, anti-tracking headers, encoding randomisation.

Idempotent scheduled sync of employees (masked NID, email, phone, branch, division, grade). Pseudonymised internal IDs, PII minimisation, opt-in/opt-out consent ledger.

SCIM 2.0LDAP/ADPII

Celery fan-out with per-wave release, per-domain rate limiting, random jitter, retry/backoff, canonical message IDs, bounce/DLQ handling, Sender-Score sanity monitoring.

Receives pixel, click (signed one-time links), submit, report, forward events; deduplicates in Redis, enriches with geo/UA, stores raw evidence, correlates to employee + campaign. Report action triggers real SOC ticket webhook.

Dimensional queries on campaign/event data; async exporters produce styled XLSX (multi-sheet, charts, conditional formatting), RFC-4180 CSV (UTF-8 BOM for Bangla), self-contained interactive HTML; signed short-lived download URLs.

Async, isolated exporters produce regulator/board/HR/SOC-ready bundles. Signed exports, tamper-evidence, bilingual (Bangla/English) labels, and full Excel compatibility including Bangla UTF-8.

Multi-sheet workbook: 1) Executive Summary KPIs, 2) Campaign Performance, 3) Employee Risk Matrix (colour-coded), 4) Raw Events. Native charts, conditional formatting, frozen header rows, filters, data validation. .xlsx via openpyxl with autofit + number formats.

.CSV RFC 4180 Â· UTF-8

Strict RFC-4180 quoting, delimiter-safe, plus UTF-8 BOM so Bangla renders correctly in MS Excel. Split into logical files (summary/campaign/employee/events) zipped for compound deliveries.

.HTML self-contained

Interactive dashboard-pack: inline SVG charts, filters and search, drill-down tables, printable layout. Zero external assets â€” GDPR/BB-safe to email. Optional password-protected (AES) variant for distribution.

Export Pipeline

  1. Request â€” POST /api/v1/reports with type + scope + format(s) + audience
  2. Authorise â€” RBAC + ABAC scope check; every export logged in audit trail
  3. Query â€” dimensional SQL over PostgreSQL / analytics views (nightly materialised rollups)
  4. Render in Celery worker â€” XLSX/CSV/HTML builder in an isolated export worker
  5. Sign & Store â€” file written to S3/MinIO, sidecar signature, metadata row in report_bundles
  6. Notify & Deliver â€” signed short-lived URL (expiry configurable) or schedule to email distribution list
Sample contents. Per campaign: sent / opened / clicked / submitted / reported counts, click-through and falling rates, top-10 at-risk employees, department & branch breakdowns, SE-Index trend line, training completion, and BDT-weighted exposure estimate. All labels switch Bangla ↚ English.

Branch → lint + unit + integration tests → SAST (Semgrep/Bandit) → SCA + SBOM (Trivy) → build & sign image (cosign) → DAST (ZAP baseline) → container scan + config scan (Kube-bench/Chekov) → deploy staging → smoke + security regression → promote with approval. Infinity gates: any critical finding blocks the build.
