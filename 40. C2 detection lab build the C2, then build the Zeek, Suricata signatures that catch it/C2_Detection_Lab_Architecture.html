🛰 C2 Detection Lab — Architecture & Design Blueprint

A GUI‑based, portable .EXE security lab that builds a command‑and‑control (C2) simulator, then writes Zeek scripts & Suricata rules that detect its own traffic — wrapped in an auditable pipeline mapped to ISO 27001, NIST CSF, NIST 800‑53, and OWASP Top 10, with reports exported as .XLSX, .CSV, and .HTML.

2 · Core Component Breakdown6 MODULES

🛤 L1 · Secure Host / SandboxFoundation & isolation

  • Isolated VM / container — no production network access
  • Host-based firewall + network namespace isolation
  • Full PCAP audit trail on every run (A.12.4 logging)
  • One-command teardown / snapshot rollback

👾 L2 · C2 SimulatorBuild the threat

  • Configurable beacon interval, jitter %, sleep window
  • AES‑GCM encrypted payload + TLS 1.3 transport
  • Multiple channels: HTTP/HTTPS, DNS tunneling
  • Benign baseline traffic generator for tuning

🐭 L3 · Zeek EngineNetwork security monitoring

  • Custom beacon.zeek — periodic-connection heuristic
  • DNS sinkhole / unusual-TLD detection script
  • JA3 / JA3S TLS fingerprint comparison
  • User-Agent & server-header signature matching

⚡ L3 · Suricata EngineSignature-based IDS

  • Custom c2_beacon.rules (alert + flowbit + tag)
  • Byte-match on beacon TLV payload structure
  • TLS SNI / JA3S rule with threat-intel reference
  • eve.json JSON alerts → normalized detection records

🖥 L4 · Portable GUI (.EXE)tkinter → PyInstaller

  • Tabs: Lab Control · Signature Builder · Live Alerts · Reports
  • Guided wizard: configure C2 → generate Zeek/Suricata sigs
  • Real-time alert dashboard with color-coded severity
  • Pin-lock + RBAC + event-driven audit log

📊 L5 · Reporting & EvidenceMulti-format export

  • .XLSX — multi-sheet workbook (openpyxl) w/ charts
  • .CSV — flat machine-readable IOC/alert data
  • .HTML — branded interactive dashboard report
  • PDF/PNG rendering for audit attachments

4 · Runtime Data FlowONE LAB RUN

1
Configure Lab — GUI submits beacon profile (interval, jitter, channel, host/port) → writes config/lab.json
2
Generate Threat — C2 server + agent spawn in sandbox; attacker triggers beacon traffic, agent encrypts with AES-GCM over TLS.
3
Capture — tcpdump/tshark writes pcap/run_001.pcap; Zeek + Suricata ingest copies in parallel.
4
Detect — Zeek beacon.zeek emits beaconing.notice; Suricata c2_beacon.rules emits eve.json alerts → normalized records with MITRE ATT&CK tags (TA0011, T1071.001).
5
Correlate + Score — rule hits cross-referenced to ground-truth labels → precision/recall, F1, alert latency.
6
Report — engine writes report.xlsx (sheets: summary, detections, IOCs, compliance), report.csv, report.html.
7
Evidence Log — hashes (SHA-256) of pcap + reports recorded for ISO 27001 A.8.10 / A.12.4 audit chain.
