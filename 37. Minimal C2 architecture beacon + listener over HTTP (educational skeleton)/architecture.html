Component Map (src/)

🔑 authn.py

Bearer-token auth with constant-time compare (HMAC), two principals: beacon console, per-IP rate limiting.

📡 listener.py

HTTP communication hub. ThreadingHTTPServer, endpoint routing, size limits, 401/429 handling.

🔋 crypto.py

Fernet (AES-128-CBC + HMAC) application-layer payload encryption + integrity.

📁 registry.py

Thread-safe in-memory beacon registry, task queue, result store.

🧭 beacon.py

Agent: encrypted check-in, allowlist task executor, result reporting.

🗂 c2logging.py

Rotating session logs + append-only JSONL audit trail + GUI log queue.

📉 reporting.py

Exports branded .xlsx / .csv / .html evidence reports.

🕹 gui.py

Colorful Tkinter console: KPIs, beacon/task/audit tables, live console, exporters.

🛡 Security stance

No shell · no persistence · allowlist tasks · token-gated APIs · audit-every-thing.
