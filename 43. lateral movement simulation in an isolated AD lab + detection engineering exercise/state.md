### Known behavior notes
- **Overlap FPs by design:** SMB admin-share run also trips the PsExec-service rule (shared `svc_create` observable); WMI and DCOM share `dcom_connect`. This models real cross-tool threshold FP.
- **Randoms are not pinned:** `run_technique` uses `random.Random(time_ns())`, so exact TP/FP/FN drift per run. Use the §5 signature as a *range*, not an exact beacon.
- **`is_lab:true`** stamps every run + detection; reports print "LAB:true" header.
- **Report CSV `techniques.csv`** columns = `technique_id, name, severity, coverage%, expected_rules, covered_rules, coverage_ratio`.
