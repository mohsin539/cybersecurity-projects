⭐ Score & verdict rules

COMPLIANT  score ≥ 80% & zero critical FAILs NON_COMPLIANT  any critical FAIL or score < 80% PENDING  enrolled, never scanned ERROR  collector failure

Severity weights: low = 1 · medium = 2 · high = 3 · critical = 4. Rules not applicable to a platform are excluded (NA).

🗺️ Guidance on scaling to a real MDM deployment

● From local to server
  • Move registry + policy to a central service
  • Agent SDK cleanup of this engine
  • TLS + mutual auth for plan sync
  • PGP/SMIME signed onboarding payloads
● Deepen telemetry
  • Patch-level inventory, cert posture
  • Network, geofence and compliance plugin checks
  • Continuous collection vs scan-on-demand
● Scale engine
  • Pluggable rule providers (YAML/JSON DSL)
  • Versioned policy history & preview
  • Scheduled scans + push notifications
