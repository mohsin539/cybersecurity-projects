📡 Wireless Network Auditor — System Architecture

GUI-based portable .exe solution for laboratory WPA/WPA2 handshake capture & security auditing of your own lab access point. Built with a hardened, privacy-aware pipeline that maps to OWASP Top 10, ISO/IEC 27001, and NIST CSF.

Python + Tkinter Scapy / Wireshark-TShark sqlite3 / AES-256 PyInstaller portable GDPR-aware Multi-report export Zero network egress Lab-scope locked

1. High-Level Overview OSI / WLAN stack

The tool passively and actively captures 802.11 frames, isolates the WPA handshake (EAPOL 1-4), builds an encrypted on-disk evidence store, runs integrity/validation checks, and produces auditable reports. All analysis stays on-device.

3. Capture Pipeline (Data Flow)

1
Interface Probe

Detect Wi-Fi adapter → request monitor mode via netsh / nmcli. Verify promiscuous+monitor support before proceeding. Enforced

2
Scope Register

Operator inputs only lab ESSID / BSSID. Allowed list stored in vault; any other BSSID is dropped at the socket.

3
Frame Capture

802.11 frames flow from radio → decode → classify (beacon / data / EAPOL / deauth / WPS). Ring-buffer PCAP snapshots every 30 s.

4
Handshake State Machine

Watch EAPOL key frames. Track sequence (M1→M2→M3→M4) per client. Persist only complete or MIC-validated handshakes. Optional MIC-of-death / deauth only on lab clients with explicit consent.

5
Analysis & Findings

AP fingerprint (OUI vendor, cipher suite, PMF, WPS exposure), client inventory, open-network detection, weak-settings scoring.

6
Evidence Recording

Encrypted store + SHA-256 hash chain (each record links previous hash). No plaintext PSK/passphrase is ever persisted.

7
Report Export

Choose HTML · CSV · XLSX · JSON (+ raw PCAP bundle). Reports embed a signed summary line for chain-of-custody.

7. Security & Privacy Controls

🔑

Key Management

Master key wrapped by Windows DPAPI; session sub-keys per run. Keys never logged.

🔒

At-rest Encryption

Every PCAP block AES-256-GCM with random IV; per-run payload keys enable clean wipe.

🧬

Integrity

SHA-256 hash chain per evidence row — tampering breaks the chain visibly in reports.

🌍

Privacy-by-design

MACs stored, no PII collection; lab-scope filtering discards foreign BSSIDs at socket.

🧹

Clean Teardown

Portable mode writes to temp dir; on exit all temp files shredded and deleted.

📄

Access Log

Local audit trail of open/lock/export events, rotated after 30 days.
